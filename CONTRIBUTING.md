# Contributing to Pad

Use the Pad repository issue tracker to report bugs and discuss changes: https://github.com/davaughnl/Pad/issues

Keep upstream copyright and license notices. Preserve mapping/profile compatibility when changing the UI. Run the branding suite and the functional checks in `tests/pad/README.md` before proposing a change.

Translations are maintained in the source catalogs. Send translation changes as pull requests to the Pad repository; Pad does not have an active Weblate project.
